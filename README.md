# shahiqimam.github.io

Interactive, scroll-through résumé of Shahiq Imam: full-stack, cyber security & DevOps.

- **Play mode**: a pixel-art side-scroller through zones (About → Experience → Skills → Projects → Security → DevOps → Credentials → Contact).
- **Quick view** (`/#quick`): a plain one-page résumé for fast reading and printing.

Built with Vite + TypeScript, hand-made SVG/CSS pixel art, no runtime dependencies.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # outputs dist/
```

All copy lives in `src/content.ts`.
